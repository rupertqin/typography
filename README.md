# TYPOGRAPHY

用 Markdown 写公众号，复制即排好版。

38 套主题，标题、引用、分割线各有装饰。草稿只留在你自己的浏览器里，不用注册，也不上传。

在线使用：**https://rupertqin.github.io/typography/**

## 功能

**写作**

- 左边写 Markdown，右边就是排好版的样子；滚动时两边一起走。
- 编辑区自带 Markdown 语法高亮：标题跟着当前主题的主色走，代码、链接、引用、表格各有着色；中文输入法组词时会自动让回纯文本，不挡候选字。
- 工具栏一点就插入小标题、引用、代码块、图表、图片位置、分割线；选中文字按 `⌘/Ctrl + B` 直接加粗。
- 用代码块写 Mermaid（语言标 `mermaid`），预览里直接出流程图、时序图、类图、甘特图。
- 撤销、重做最多 100 步，手滑清空或换掉示例也能撤回。
- 粘贴截图会自动变成图片位置，不用手动敲语法。
- 编辑区底部随时显示字数和预计阅读时长。

**主题**

- 38 套主题：简约、书香、报纸、杂志、手账、终端、霓虹、水墨、卡片流……，以及从 [md.doocs](https://md.doocs.org) 移植过来的经典、优雅、清爽。
- 标题、引用、分割线、列表符号都是主题的一部分：方格本是双线夹字，终端是 `$` 提示符加光标，朱印带色块序号，时间轴带圆点，清单带 `STEP 01` 标签。
- 按文章类型挑：技术编程、干货教程、资讯观点、商业职场、情感随笔、读书文艺、生活美食、活动节日，每类还标了可用套数。
- 选不下来就随机换一个，换完不满意能撤回上一套。
- 主题列表里的卡是真实排版缩出来的小样，不是截图——点开之前就知道长什么样。

**配色与字体**

- 换一个主色，标题、引用、加粗、分割线一起换成同一色系；非标题部件也能用同一套色板单独调色。
- 11 种预设色，或者用自定义取色器挑任意颜色。
- 换主题会保留你调过的颜色。配色面板可以拖到一边，边调边看。
- 字号五档、字体八种（黑体、宋体、楷体，以及苹果系统的细体），预览里看到的比例就是复制出去的比例。
- 只想看整篇结构时，把预览缩到 50%。

**排版细节**

- 行高五档、段间距五档（在主题原本的疏密上整体缩放，标题仍比正文更疏）。
- 链接色（微信蓝 / 主题色 / 自定义）、引用底色（跟随主题 / 无背景 / 主题色浅底 / 自定义）。
- 标题样式：先选 H1–H6，再给这一级选默认 / 自选颜色 / 下边框 / 左边框；只有「自选颜色」才展开颜色选项（含「跟随主题」），并会去掉标题底色。
- 80+ 套代码配色（GitHub、Atom One、Nord、Tokyo Night、Monokai……），与文章主题解耦，可自由组合；默认「跟随主题」。
- 这些设置和主色一样：预览即时生效、复制后同样生效、换主题后保留。

**复制**

- 一键复制，粘到公众号后台就是预览里的样子，不用再逐段补样式。
- 复制出来是干净的富文本：不带多余标记，也不引用任何外部资源。
- 代码块的缩进和换行不会塌，长表格在手机上能横向滑动。
- 图表粘过去是**真矢量图**：文字可选中、缩放不糊，箭头连线不掉（复制前会把箭头、图标、渐变展开成微信认的写法）。
- 公众号不收外链图，图片位置会留成占位框，粘过去在后台补图，不会出现打不开的破图。

**本地优先**

- 草稿、主题、配色都存在浏览器里，关掉再打开还在。
- 不需要注册登录，文章不上传到任何服务器。

**Markdown**

- 支持 GFM、表格、代码高亮、Mermaid 图表、上标下标、脚注、删除线，以及 `++下划线++` / `==高亮==` / `~波浪线~`。
- 代码语言不再限于十几门：常见语言随包首发，长尾语法按需加载，加载失败自动退化成纯文本。
- 脚注按引用顺序编号列在文末；写进脚注里的外链会自动补出完整地址。

### 本地运行

```bash
npm install
npm run dev               # http://localhost:4321/（端口被占用会自动顺延；局域网/手机调试加 `-- --host`）
npm run check:themes      # 校验主题与代码配色数据（改了这两份源就跑）
npm run verify            # 主题校验 + 冒烟 + 构建
npm run preview           # 预览 dist/
```

## 说明

- 公众号会丢弃 class，样式全部写成内联；内容外面再包一层容器，粘过去才不会只剩裸段落。
- 字体只能声明读者设备自带的系统字体，所以给的是字体栈而不是 webfont；细体和极细用字重表达，比小众字体名更容易通过公众号清洗。
- 主题是**一个主题一个文件**：`src/lib/themes/catalog/<主题 id>.ts`，都用 `new Theme({...})` 定义（只写与基础样式表不同的键）；公共机制（字体、调色板、装饰 helper、基础样式表、注册表）在 `src/lib/themes/` 里，顺序由 `src/lib/themes/index.ts` 决定。
- 代码配色同理收在一个目录里：`src/lib/code-themes/catalog.ts` 是 82 套数据（一段一套），`theme.ts` 是 `CodeTheme` 类（构造期校验 token 形态并冻结实例，带 `swatch()/palette()`），`index.ts` 负责实例化与查表 API。
- 改完主题或配色跑 `npm run check:themes`，它守住数量、顺序、31 个样式键、装饰函数与 token 完整性。
- 代码配色的 token 颜色是内联声明而不是 class，运行时不解析 CSS，复制产物天然全内联。配色从 `highlight.js/styles` 一次性搬到源文件里，升级 highlight.js 不会自动跟进（`HLJS_VERSION` 与安装版本不一致时 `check:themes` 会提醒）。
- 语法按需加载时会从 jsDelivr 取同版本语法（`highlight.js@<本地版本>/es/languages/*.min.js`）；只在预览期发生，复制出去的正文不带任何外链。
- Mermaid 的 SVG 在复制时清洗：展开箭头/图标/渐变、`foreignObject` 里的 HTML 标签转成真正的 `<text>`、深灰墨色转 `currentColor`、`dominant-baseline` 转 `dy`、尺寸归一到公众号列宽（≤677px），最后去掉 `defs`/`id`/`class`。
